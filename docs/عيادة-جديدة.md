# تركيب نسخة لعيادة جديدة

الملف ده للحالة اللي انت فيها: عندك السيستم، وعايز تديه لدكتور تاني — تجربة
أو بيع.

**الوقت المطلوب: حوالي ١٥ دقيقة لكل عيادة.**

---

## القاعدة الحاكمة: كل عيادة قاعدة بيانات لوحدها

**كود واحد. قاعدة بيانات لكل عيادة. نشرة لكل عيادة.**

مش لأنها أسهل — لأن أي حل تاني معناه إن ملفات مرضى عيادتين في قاعدة واحدة،
وده خطر مش لازم تشيله وانت بتبيع.

والمكسب إن الترقيات مجانية: تعدّل الكود مرة، وكل العيادات بتاخده تلقائي، من
غير ما بيانات حد تتلمس.

| | |
|---|---|
| الكود | واحد لكلهم — نفس المستودع |
| قاعدة البيانات | **واحدة لكل عيادة** |
| النشرة والرابط | واحدة لكل عيادة |
| اسم العيادة واللوجو والدكاترة والأسعار | جوّه قاعدة بيانات كل عيادة |

---

## ⚠ حاجة لازم تعرفها قبل ما تبعت أي لينك

**لو بعت لينك عيادتك انت لحد يجرّب، هو بيدخل على قاعدة بياناتك انت.**

يعني هيشوف مرضاك، وأي مريض هو يسجّله هيتحط في ملفاتك. مش نسخة تجريبية —
دي عيادتك.

**اعملّه نسخة لوحده.** الخطوات تحت، وبتاخد ربع ساعة.

---

## الخطوات

### ١. قاعدة بيانات جديدة

١. [supabase.com/dashboard](https://supabase.com/dashboard) → **New project**
٢. سمّيه باسم العيادة (مثلًا `clinic-drahmed`)
٣. اختار **Region: Frankfurt** — أقرب واحد لمصر
٤. اكتب Database Password واحفظها عندك
٥. استنى دقيقتين لحد ما يخلص

### ٢. ركّب العيادة

١. جوّه المشروع الجديد: **SQL Editor** → **New query**
٢. الزق ملف **`supabase/SETUP-CLINIC-ONLY.sql`** كامل
   (من GitHub → فولدر `supabase` → زرار **Copy raw file**)
٣. **Run**

### ٣. افتح الـ schema

**Settings** → **API** → **Exposed schemas** → ضيف `clinic` → **Save**

ومن نفس الصفحة انسخ **Project URL** و **anon / publishable key**.

### ٤. نشرة جديدة

١. [vercel.com](https://vercel.com) → **Add New** → **Project**
٢. اختار نفس المستودع `next-campaign`
   > أيوه، **نفس** المستودع. الكود واحد.
٣. سمّي المشروع باسم العيادة
٤. قبل ما تدوس Deploy، افتح **Environment Variables** وحط الأربعة دول:

   | الاسم | القيمة |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | نفس URL العيادة |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | نفس مفتاح العيادة |
   | `NEXT_PUBLIC_CLINIC_SUPABASE_URL` | URL العيادة |
   | `NEXT_PUBLIC_CLINIC_SUPABASE_ANON_KEY` | مفتاح العيادة |

   > ليه الأربعة بنفس القيمة؟ لأن الكود ده أصله موقع مطبوعات فيه عيادة. في
   > نسخة عيادة لوحدها، الاتنين بيشاوروا على نفس المكان — والمتغيرين الأولين
   > موجودين عشان الموقع يفتح من غير ما يقول «محتاج إعداد».

٥. **Deploy**

### ٥. سلّمها

الرابط هيبقى `اسم-المشروع.vercel.app/clinic`

| | |
|---|---|
| الموبايل | `01000000009` |
| كلمة السر | `clinic2026` |

**قوله يغيّرها أول ما يدخل.**

## ٦. ظبّطها باسمه — من غير أي كود

كل ده من جوّه السيستم، **الإعدادات**:

| الحاجة | مكانها |
|---|---|
| اسم العيادة | الإعدادات ← بيانات العيادة |
| **اللوجو** | الإعدادات ← لوجو العيادة ← اختار صورة |
| العنوان والتليفون | الإعدادات ← بيانات العيادة |
| سعر الكشف والإعادة | الإعدادات ← الأسعار |
| مقاسات الطباعة | الإعدادات ← الطباعة |
| **اسم الدكتور واللقب والتخصص ورقم النقابة** | الفريق ← الحساب |
| **أدويته** | الأدوية ← استيراد قايمة |

اللوجو واسم الدكتور بيتطبعوا على الروشتة لما تشغّل **«اطبع الترويسة»** — أو
سيبها مقفولة لو ورقه مطبوع فيه الترويسة أصلًا.

## كتالوج الأدوية

كل عيادة جديدة بتيجي بـ **٩٨ دوا** من أشهر أدوية السوق المصري، بالاسم
اللاتيني والعربي. شغّالة من أول دقيقة.

**وقايمة الدكتور نفسه أحسن منها بكتير.** من **الأدوية** ← **استيراد قايمة**:

- الزق من Excel (انسخ الأعمدة والزقها زي ما هي)
- أو ارفع ملف CSV
- أو اكتب اسم في كل سطر

السيستم بيقرا الأعمدة لوحده، **وبيوريك النتيجة قبل ما يحفظ** عشان تتأكد إن
الأعمدة نزلت مكانها صح. الدوا الموجود بيتحدّث مش بيتكرر.

**منين تجيب قايمة؟**
- قايمة الدكتور نفسه أو صيدلية بيتعامل معاها — دي الأفضل بفارق
- تصدير من أي سيستم قديم كان بيستخدمه
- الترتيب المتوقع للأعمدة: `الاسم التجاري · الاسم بالعربي · المادة الفعالة · الشكل · التركيز`

**مهم:** الاسم بالعربي مش رفاهية. من غيره الدكتور اللي بيكتب «كونكور» مش
هيلاقي Concor.

---

## لما تعدّل الكود

تدفع التعديل على GitHub مرة واحدة، وكل نشرات العيادات بتاخده تلقائي.

**بيانات أي عيادة مابتتلمسش** — التحديث بيغيّر الكود بس.

لو التعديل فيه تغيير في قاعدة البيانات، هتحتاج تلزق ملف الإعداد الجديد في كل
مشروع Supabase. الملف آمن لو اتشغّل أكتر من مرة.

---

## الحدود اللي تعرفها وانت بتبيع

**الخطة المجانية في Supabase** كفاية لعيادة واحدة صغيرة، بس **مافيهاش نسخة
احتياطية ترجع منها**. لعيادة بمرضى حقيقيين ده مش مقبول — راجع
[`docs/العيادة.md`](العيادة.md) قسم النسخة الاحتياطية.

**كل عيادة لازم:** تشفير قرص اللاب، وقفل بـ PIN، وكلمة سر متغيّرة. الاتنين
الأولانيين مش اختيار — السيستم بيحفظ بيانات مرضى على الجهاز عشان يشتغل من غير
نت.

**ده سيستم تسجيل وطباعة، مش نظام قرار طبي.** مفيش فحص تعارض أدوية. قول ده
للدكتور صراحة قبل ما يشتري.
