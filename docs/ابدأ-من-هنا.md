# ابدأ من هنا

الملف ده مكتوب لك انت — مش لمبرمج. كل حاجة فيه أمر تنسخه وتلزقه.

الأوامر كلها بتتكتب في **PowerShell** جوه فولدر المشروع:
`G:\Aphrodite\2026\APP\next-campaign`

---

## الجزء الأول: تشوف الموقع على جهازك

### أول مرة بس

```bash
npm install
```

بياخد دقيقة أو اتنين. مش هتحتاج تعيده تاني.

### كل مرة عايز تشوف الموقع

```bash
npm run preview:start
```

استنى لحد ما يكتب لك:

```
- Local:    http://localhost:3000
- Network:  http://192.168.x.x:3000
```

- **من الكمبيوتر:** افتح `http://localhost:3000`
- **من تليفونك:** لازم يكون على نفس الواي فاي، وافتح عنوان الـ **Network**
  (بيتغير مع كل شبكة — خد اللي ظاهر قدامك)

الأمر ده بيشغّل نسخة من الموقع ببيانات تجريبية جاهزة (٢٤ منتج بأسعار وطرق
طباعة). **مش محتاج Supabase ولا إنترنت.**

عشان توقفه: اضغط `Ctrl + C` في نفس النافذة.

### وانت خلصت

```bash
npm run preview:off
```

مهم قبل ما تنشر أو تحفظ أي تعديل. لو نسيت، الأمر ده بيقولك انت في أنهي وضع:

```bash
npm run preview
```

## الجزء التاني: تعدّل

### النصوص (العناوين، الأزرار، الكلام)

كلها في ملف واحد: **`web/lib/strings.ts`**
افتحه بأي محرر نصوص، غيّر الكلام اللي بين علامتي التنصيص، احفظ.
الموقع بيتحدّث لوحده وانت شغّال.

### الألوان والشكل

في أول **`web/app/globals.css`**. أهم سطرين:

```
--brand: #d8412f;    /* لون الشركة الأساسي */
--paper: #ffffff;    /* لون الخلفية */
```

### المنتجات والأسعار

دلوقتي بتتعدّل في ملف **`supabase/seed.sql`** — الأسعار والطرق وأماكن الطباعة
كلها هناك بالعربي. بعد أي تعديل:

```bash
npm run preview:dump
```

**بعد المرحلة الجاية (P4)** هيبقى فيه لوحة تحكم على الموقع نفسه، وهتضيف المنتجات
منها من غير ما تفتح أي ملف.

### مهم: الأسعار اللي في الموقع دلوقتي تجريبية

الأرقام اللي موجودة معقولة لكن **مش أسعارك**. قبل ما تنشر للناس، لازم تتبدّل
بأسعارك الحقيقية، ورسوم الكليشيه الحقيقية لكل طريقة. ومفيش صور منتجات لسه —
الكروت بتعرض اسم المنتج بدل الصورة، عن قصد، عشان محدش يحط صور من الإنترنت
ونتسلّم حاجة شكلها مختلف.

## الجزء التالت: تنشره للناس على الإنترنت

### قبل ما تبدأ — اقرا ده

الموقع دلوقتي **بيشتغل كامل من ناحية العميل**: بيتصفّح، بيحسب التكلفة، بيرفع
اللوجو، وبيبعت الطلب برقم طلب ورسالة واتساب جاهزة.

الموقع **شغّال كامل** دلوقتي — من ناحية العميل ومن ناحيتك.

**قبل ما تعلن عنه للعملاء لازم:**
1. **تغيّر كلمة سر المدير** — شوف الجزء الرابع تحت
2. أسعارك الحقيقية تبقى مدخّلة بدل الأسعار التجريبية
3. صور المنتجات تبقى موجودة
4. **رقم الواتساب يتحط في الإعدادات** — من غيره زرار الواتساب مش بيظهر أصلاً
   في صفحة تأكيد الطلب (زرار بيروح لا حاجة أسوأ من مفيش زرار)

---

### خطوة ١ — قاعدة البيانات (Supabase)

1. ادخل [supabase.com](https://supabase.com) واعمل حساب.
2. **New Project**. اختار اسم، واختار المنطقة **Frankfurt** (الأقرب لمصر).
   احفظ الباسورد اللي هيطلبه منك في مكان أمين.
3. **مشروع جديد مخصص للموقع ده لوحده.** متستخدمش مشروع الاسكوتر ولا ملك
   التوقعات — القاعدة الواحدة لتطبيقين كلّفتنا تلات أعطال صامتة قبل كده.
4. استنى دقيقتين لحد ما المشروع يجهز.
5. من القايمة الجنب: **SQL Editor** → **New query**.
6. افتح ملف `supabase\SETUP-ALL-IN-ONE.sql` عندك، انسخه **كله**، الزقه في
   المربع، واضغط **Run**.
   لو طلع أخضر خلاص — قاعدة البيانات جاهزة بكل المنتجات.
   (الملف آمن لو اتشغّل مرتين.)
7. ⚠ **فعّل الدخول المجهول** — من غير الخطوة دي رفع اللوجو مش هيشتغل خالص:

   **Authentication** → **Sign In / Providers** → دوّر على
   **Anonymous sign-ins** → **Enable** → **Save**.

   ليه: العميل بيرفع لوجوه من غير ما يعمل حساب. عشان الملف يتخزن في فولدر
   مخصوص ليه ومحدش تاني يوصله، لازم يكون ليه هوية — والهوية دي بتتعمل
   تلقائياً وقت الرفع. لو الخيار ده مقفول، الرفع بيرمي خطأ والعميل مش هيفهم
   ليه.

8. **Project Settings** → **API**، وانسخ حاجتين:
   - **Project URL**
   - **anon public** key (في المشاريع الجديدة اسمه **publishable key**)

المفتاح ده معمول عشان يبقى في المتصفح، مفيش مشكلة إنه يبان.
**الحاجة الوحيدة اللي عمرها ما تتنسخ لأي مكان هي `service_role`
(أو `secret key`).**

### لو ملف الـ SQL وقف في النص

الملف ٣٣٠٠ سطر تقريباً. لو محرر Supabase اتعب معاه:
افتح `supabase/migrations/` والصق الملفات **واحد ورا التاني بالترتيب الرقمي**،
وبعدين `supabase/seed.sql` في الآخر. نفس النتيجة بالظبط.

**الترتيب مهم**: الملف رقم `...006_rls.sql` بيسحب الصلاحيات، واللي بعده
بيرجّعوها بالاسم. تشغيلهم بترتيب مختلف بيسيب الموقع من غير صلاحيات قراءة.

### لو الجزء بتاع Storage رمى خطأ

نادر، لكن لو حصل: من **Storage** اعمل دلوين بالإيد —
`product-media` (**Public**) و `customer-artwork` (**Private**) — وبعدين شغّل
الملف تاني. هو آمن لو اتشغّل مرتين.

### خطوة ٣ — تنشر (Vercel)

Vercel هي الشركة اللي عاملة Next.js، والاستضافة عندهم مجانية للموقع ده.

1. ادخل [vercel.com](https://vercel.com) وسجّل **بحساب GitHub**.
2. **Add New → Project** → اختار `next-campaign`.
3. **مهم:** في خانة **Root Directory** اضغط **Edit** واختار **`web`**.
   (المشروع فيه أكتر من فولدر، والموقع في `web`.)
4. افتح **Environment Variables** وحط التلاتة دول:

   | الاسم | القيمة |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | الـ Project URL من Supabase |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | الـ anon public key |
   | `NEXT_PUBLIC_SITE_URL` | سيبها فاضية دلوقتي، هنرجعلها |

5. **Deploy**. بعد دقيقتين هيديك لينك شكله
   `next-campaign-xxxx.vercel.app`.
6. ارجع لـ **Settings → Environment Variables**، وحط في
   `NEXT_PUBLIC_SITE_URL` اللينك ده بالظبط (من غير `/` في الآخر)، وبعدين
   **Deployments → … → Redeploy**.

الخطوة الأخيرة دي مش شكلية: من غيرها معاينة الواتساب وخريطة الموقع لجوجل
هيبقوا بيشاوروا على `localhost`.

---

### خطوة ٤ — الدومين بتاعك

لو معاك دومين (زي `nextcampaign.com`):

1. في Vercel: **Settings → Domains → Add**، اكتب الدومين.
2. Vercel هيديك سطرين (`A` و `CNAME`) تحطهم عند الشركة اللي شاريه منها.
3. لما يتفعّل، **غيّر `NEXT_PUBLIC_SITE_URL` للدومين الجديد** و Redeploy.

## الجزء الرابع: لوحة التحكم

الرابط: **`/admin`** — يعني `nextcampaign.com/admin` أو
`http://localhost:3000/admin` محلياً.

### أول دخول — اعمله فوراً

التثبيت بيعمل لك حساب مدير:

| | |
|---|---|
| الموبايل | `01000000000` |
| كلمة السر | `campaign2026` |

**⚠ غيّرها أول ما تدخل.** كلمة السر دي مكتوبة في ملفات المشروع، وأي حد يقرا
المستودع يعرفها.

`/admin` ← **المستخدمين** ← جنب اسمك اضغط **غيّر كلمة السر**.
ومن نفس الصفحة تضيف موظفين وتحدد مين مدير ومين موظف عادي.

### الشاشات

| الشاشة | بتعمل إيه |
|---|---|
| **اليوم** | كام طلب جديد، كام مستني معاينة، وإيه اللي ميعاده قرّب |
| **الطلبات** | كل الطلبات، بحث بالموبايل أو الاسم أو رقم الطلب |
| **الطلب** | كل التفاصيل، **تحميل ملفات العميل**، تغيير الحالة، العربون |
| **أمر شغل** | صفحة A4 تطبعها وتديها للورشة — فيها النص المطلوب بخط كبير ومفيش أسعار |
| **المنتجات** | إضافة وتعديل، وبيقولك كل منتج ناقصه إيه قبل ما تنشره |
| **الفئات والمناسبات** | إضافة فئة أو مناسبة أو طريقة طباعة أو خط |
| **الإعدادات** | التواصل، رقم الواتساب، نسبة الضريبة |

### حاجات اتعملت عن قصد

**حالة الطلب بتتغير بالأزرار بس.** الأزرار اللي بتظهر لك هي الانتقالات المسموحة
من الحالة الحالية — مش هتلاقي «اتسلّم» على طلب لسه جديد. وده مفروض في قاعدة
البيانات نفسها، مش في الشاشة.

**الإلغاء لازم سبب.** لإن «ليه ده ماتنفذش؟» سؤال بيتسأل بعد تلات شهور.

**العربون مش حالة.** ممكن يتحصّل في أي وقت، فهو خانة مستقلة عن مسار الطلب.

**مفيش زرار مسح لمنتج اتطلب قبل كده.** أخفيه بدل ما تمسحه — الطلب القديم شايل
اسمه وسعره، بس الصف نفسه هو الرابط الوحيد لـ«عملنا كام من ده».

**أمر الشغل مفيهوش أسعار.** الورشة محتاجة تعرف تعمل إيه، مش باعوا بكام — وورقة
فيها إجمالي بتوصل لعميل في الآخر.

## لو حاجة وقعت

| اللي بتشوفه | السبب |
|---|---|
| شاشة **«الموقع محتاج إعداد»** | المفاتيح ناقصة. محلياً: `npm run preview:start`. على Vercel: راجع الـ Environment Variables |
| الكتالوج فاضي بعد النشر | ملف `SETUP-ALL-IN-ONE.sql` ما اتشغّلش في Supabase، أو اتشغّل في المشروع الغلط |
| المنتجات القديمة ظاهرة بعد ما عدّلت | انت في وضع المعاينة. `npm run preview:off` |
| لينك الواتساب مش بيعرض معاينة | `NEXT_PUBLIC_SITE_URL` مش مظبوط، أو المنتج مالوش صورة |
| `npm` مش شغال | Node مش على الـ PATH. استخدم `G:\dev-tools\node\node.exe` أو ضيفه للـ PATH |
| رفع اللوجو بيقول «مشكلة في رفع الملف» | **الدخول المجهول مش مفعّل** في Supabase — شوف خطوة ٧ |
| `/admin` بيقول «محتاج تدخل بحساب إدارة» | كلمة السر أو الموبايل غلط، أو الحساب موقوف |
| لوحة التحكم فاضية بالكامل | دخلت بحساب مش مدير. الجداول بترجع فاضية بالـ RLS، مش بتقفل الصفحة |
| «المنتج ده اتطلب قبل كده» | مش بيتمسح عن قصد — أخفيه من زرار «إخفاء» |
| زرار النشر بيقول «قبل النشر…» | المنتج ناقص سعر عند الحد الأدنى أو طريقة أو مكان طباعة. القايمة بتقولك الناقص |
